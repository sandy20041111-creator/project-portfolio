# 熱感應風扇系統

**類比電路實驗期末專題**｜組員：林依辰、陳昱維

## 專題簡介

設計一套能即時感測環境溫度、超過門檻時自動啟動風扇的類比控制電路，兼顧舒適度與用電效率。

## 系統功能

- 以 NTC 10K 熱敏電阻感測環境溫度
- 溫度超過門檻（30°C）時自動啟動風扇
- 未達門檻時可透過按鈕手動開啟
- 以 Arduino 顯示即時溫度

## 電路設計

1. **溫度感測**：NTC 熱敏電阻與固定電阻組成分壓器，溫度變化轉換為電壓變化
2. **訊號放大**：第一顆 LM741 作為同相放大器，放大分壓電壓
3. **門檻比較**：第二顆 LM741 作為比較器，與參考電壓比較決定是否啟動
4. **負載驅動**：以邏輯準位 N-MOSFET（IRLZ44N）作為開關，控制 USB 風扇電源

電路先以 **PSpice** 模擬驗證，再於洞洞板上焊接實作。

## 使用技術

| 類別 | 內容 |
| --- | --- |
| 類比電路 | 分壓器、同相放大器、比較器、MOSFET 開關 |
| 主要元件 | NTC 10K、LM741 ×2、IRLZ44N、1N4007 |
| 工具 | PSpice、Arduino UNO、洞洞板焊接 |
