# 寵物智慧餵食小幫手

**微處理機實驗期末專題**｜組員：林依辰、陳昱維

## 專題簡介

針對飼主因工作或課業無法按時餵食寵物的問題，設計一套能監測飼料餘量並自動補料的智慧餵食系統。與市售只能定時出料的餵食器不同，本系統以「時間到」加上「重量低於門檻」雙重條件判斷是否出料，避免過量餵食。

## 系統功能

- **重量監測**：BMH01220 重量感測模組以 I2C 回傳 16-bit 重量數據，即時掌握飼料餘量
- **自動補料**：條件成立時以 PWM 驅動 MG90S 伺服馬達開啟閘門，重量回到門檻後關閉
- **安全防護**：紅外線感測器透過 EXTI 中斷偵測碗是否在位，碗被打翻或移開時立即停止馬達
- **狀態顯示**：GPIO 控制紅／綠 LED，綠燈表示飼料充足、紅燈表示不足
- **手動操作**：手動餵食與緊急停止按鈕（緊急停止為最高優先權中斷）
- **遠端監控**：透過 UART 將重量與餵食狀態傳至電腦端 Tera Term

## 使用技術

| 類別 | 內容 |
| --- | --- |
| 主控 | HOLTEK HT32F52352、ESK-310 多功能實驗板 |
| 感測 / 致動 | BMH01220 重量感測模組、紅外線感測器、MG90S 伺服馬達 |
| 周邊介面 | I2C、PWM、GPIO、EXTI、UART |
| 監控工具 | Tera Term |
