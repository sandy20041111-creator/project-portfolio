### Large-Vehicle-Ahead Event Warning System

**大型車之前車事件辨識與通報顯示對本車早期預警**

當後車視線被大型車（如公車）遮蔽時，於大型車煞車前即辨識前方危險事件，並對後車提出早期預警之車載系統。

**我的負責部分：**

- 弱勢用路人事件判定：行車路徑梯形 3×3 九宮格 ROI，結合 OCR 讀取之車速與目標於 ROI 中的位置決定警示等級
- TensorRT 推論加速（約 15 → 35 FPS）與 Jetson Nano 部署

主要成果：

- 115 年中國工程師學會學生分會工程論文競賽－入圍
- 2026 全國大專院校智慧創新暨跨域整合創作競賽－參賽

[查看專題資料](projects/大型車之前車事件辨識與通報顯示對本車早期預警)
